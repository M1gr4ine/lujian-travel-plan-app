# 计划库折角便签与展开动画设计

## 目标

把计划库中的普通缩略图框改为折角便签纸。用户点击整张计划卡时，缩略图便签从原位置连续展开为计划详情页；返回时反向收回。动画优先保证稳定和触摸响应，不改变计划数据、缩略图来源及详情页功能。

## 视觉

- 保留双列计划库和“添加计划”入口尺寸。
- 折角便签只承载缩略图；灰色标题、目的地和日期继续位于框外，保持原有轻量层级。
- 便签采用现有米白纸色、粗墨色描边和圆角；右上角切出折角，以浅色三角面和墨色折线表现纸张翻折。
- 缩略图填充便签内部，框线由原来的 2dp 加粗到 3dp；框外信息区保持三行单行省略；管理模式勾选框移到左上，避开右上折角。
- 详情页保持现有排版。过渡期间便签外形逐渐放大并解除卡片圆角，详情顶部栏和正文在展开后段淡入。

## 动画

- 使用 Compose 共享边界过渡，键为 `plan-note-{planId}`，源为缩略图便签框，目标为详情页根纸张容器。
- 点击后源卡保持原位，由共享层以 GPU 缩放和边界插值展开；不制作位图快照，不在每帧重新解码缩略图。
- 主过渡时长 280ms，使用项目现有的强缓出曲线；详情内容延迟 55ms 淡入，兼顾纸张展开感与点击响应。
- 返回执行完全对称的收回动画。
- 首页地图进入详情仍使用普通导航动画；共享展开仅用于计划库，避免无源卡片时出现错误起点。
- 系统启用减少动画时停用共享缩放，仅保留短淡入淡出。

## 结构

- 新增可复用的折角便签 `Shape` 与描边绘制修饰符，独立负责轮廓、折角和点击区域。
- `PlanPreviewCard` 负责框内缩略图、框外灰色元数据及管理状态，只将缩略图便签暴露为共享边界源。
- `LujianRoot` 持有共享过渡作用域，并把当前导航的动画作用域传给计划库与详情页。
- `PlanDetailScreen` 将根纸张区域标记为同一共享边界目标，正文自身不参与尺寸插值。
- 详情路由关闭原有水平滑入，防止共享展开与页面滑动叠加；其他路由维持现有动画。

## 交互与异常

- 动画进行期间忽略重复点击，防止重复压入相同详情路由。
- 缩略图缺失时占位图标仍参与相同动画。
- 管理模式只执行选择缩放，不触发详情共享动画。
- 计划在过渡期间被删除或列表刷新时，导航回退到计划库，不保留悬空共享元素。

## 验证

- Compose 测试验证便签语义、管理模式不打开详情、普通模式只导航一次、返回后原卡仍可见。
- 构建与 Lint 覆盖共享过渡 API 和减少动画分支。
- 本轮先在 Android 虚拟机验证点击展开、系统返回收回、连续打开不同卡片和无缩略图回退；Huawei PLA-AL10 真机验证留待用户下一轮确认。
- 使用 `adb shell dumpsys gfxinfo com.lujian.travelplan framestats` 记录展开与收回帧，重点检查长帧和首帧缩略图解码。
